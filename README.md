# Premier League Performance Analysis (2016-2024)

## Overview
A Power BI dashboard analyzing 9 seasons of Premier League data exploring club dominance, league trends and performance patterns.

## Questions Answered
- Which clubs dominated the Premier League from 2016-2024?
- Has the league become more competitive over time?
- Does scoring more goals guarantee more points?
- Which clubs consistently finished in the top 4 and relegation zone?

## Tools Used
- Microsoft Excel — data cleaning and preparation
- Power BI — data visualization and dashboard building

## Key Insights
- Manchester City dominated with a record 100 points in one season
- The league average points per season remained competitive around 52-54 points
- Strong correlation between goals scored and points accumulated
- Hull City, Middlesbrough and Sunderland were most frequently relegated
